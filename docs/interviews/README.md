# Interviews

現場経験者・専門家へのインタビューをまとめるカテゴリです。

## Purpose

ダイビングに関する知識は、書籍や論文だけではありません。

現場で積み重ねられた経験、事故から得られた教訓、長年の実践によって培われた知恵も、未来へ残すべき大切な知識です。

DKBでは、インタビューを一次資料として保存し、その内容を整理・体系化して記事へ反映していきます。

---

## Interview Flow

```text
Interview
```
