# Diving Knowledge Base (DKB)

> **Knowledge saves lives.**
>
> **知識は、命を守る。**

DKB（Diving Knowledge Base）は、ダイバーが自分自身とバディの命を守るための知識を、未来へ残すオープンな知識基盤です。

---

## 🎯 Mission

ダイバーが安全に潜り続けるための知識を整理し、誰もが学べる形で未来へ残します。

## 🌏 Philosophy

DKBは、知識を競う場所ではありません。

知識を共有し、
互いに学び、
未来へ受け継ぐ場所です。

現場経験を尊重し、
科学的知見を大切にし、
安全を第一に考えます。
